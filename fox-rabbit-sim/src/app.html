Rules

Version 1 — the starting rules

A sealed meadow. Nothing comes in, nowhere is safe.

  1. Scatter the surviving rabbits at random, one per cell.
  2. Drop each fox's sticky note. It covers a 2 × 2 patch.
  3. Every rabbit under a note is eaten.
  4. A fox that caught 3 or more in that one drop survives; fewer and it starves.
  5. Every survivor — rabbit or fox — doubles for the next generation.

The fox almost always starves in turn 1, and nothing brings it back.

Every run with the same seed is identical — that is what makes it reproducible. Change the seed to see how differently the same rules can play out.
